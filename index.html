Venta de Repuestos para Electrodomésticos

Como servicio complementario, ofrecemos consulta y venta de repuestos para diferentes marcas y tipos de electrodomésticos. Atención en Bogotá y envíos a diferentes ciudades de Colombia.

Repuestos para estufas

Quemadores, perillas, válvulas, parrillas, vidrios y otros componentes.

Repuestos para hornos

Vidrios de puerta, termostatos, manijas, resistencias y accesorios.

Repuestos para neveras

Bandejas, controles, componentes y piezas para diferentes referencias.

Repuestos para lavadoras

Bombas, transmisiones, mangueras, componentes y accesorios.

Repuestos para secadoras

Repuestos para calentadores

Consulta piezas para calentadores de agua a gas y eléctricos.

Campanas extractoras
